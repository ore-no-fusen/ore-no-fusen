✅ writeがホーム — ログイン済みなら常にwrite画面から始まる

✅ noteを「消す」 → 通知を閉じてからwrite画面へ遷移

✅ 画像はカーソル位置に挿入 — 📷タップで選択した画像を本文の好きな場所に挿入（![](fusen_img_...)）

✅ トークン自動更新 — 「PCに送る」前に期限を確認・期限切れなら自動リフレッシュ。session expired時はlogin画面へ遷移

✅ 下書きはローカル保存 — IndexedDB使用・Drive不使用。テキスト+画像Blobをそのまま保持

✅ 一覧から編集 — ノートタップで内容をエディタに読み込む（pendingHydrate経由）

✅ ＋ボタンで新規作成 — エディタをクリア・currentDraftId=nullにしてwrite画面へ

✅ 削除 — 各ノートの🗑️タップで即削除（確認ダイアログなし）→ IndexedDB削除 → 一覧を再取得

✅ 保存分岐 — 「iPhoneに置いておく」: currentDraftIdがあれば上書き（put）、なければ新規作成（add）

✅ 送信後クリーン — 「PCに送る」成功後、currentDraftIdの下書きをIndexedDBから削除

🆕 【Phase 10】チェックボックス行頭挿入 — ☑ボタンをタップすると、カーソル位置に関わらず行頭に - [ ] を挿入する

🆕 【Phase 10】チェックボックスをタップでON/OFF — 編集中に - [ ] / - [x] が実際のチェックボックスとしてレンダリングされ、タップで切り替え可能

🆕 【Phase 10】タグサジェスト — 🏷️ボタンをタップすると過去に使ったタグが候補として表示される。タップで即追加、入力すると絞り込まれる。使用タグは fusen_known_tags（localStorage）に自動保存

🆕 【Phase 10】ノンブロッキック送信 — 「PCに送る」を押した瞬間にエディタがクリアされ次の操作が可能。送信はバックグラウンドで実行され、完了・失敗を右上トーストで通知。Drive API もキャッシュ＋並列化で高速化
