# エンドロール（お祭り奉納帳）機能 計画書

## 目的
無料を守りつつ、応援（寄付）を受け取り、応援してくれた人を「お祭りの奉納帳」エンドロールで称える。
Everything 型の「無料＋投げ銭」。お金の多寡ではなく**早さ**を称える。

## 確定した設計（2026-06-20 ロック）
- **表示**: 映画のクレジット風に、自動で上へ流れる＋ループ
- **並び/大きさ**: 早く応援した人ほど大きく・上（時刻順）。**金額は一切反映しない・表示しない**
- **見た目**: 夜祭り／夏祭り（藍×金×提灯）
- **同意**: 寄付時に「表示名」を書いた人だけ載る（opt-in。空欄＝匿名＝載らない）
- **寄付の窓口**: Stripe Payment Link（PayPay 対応＋カード／表示名カスタム欄／webhook あり）

## アーキテクチャ
```
寄付者 → Stripe Payment Link（PayPay等／「表示名」欄）
       → checkout.session.completed webhook
       → Cloudflare Worker（既存基盤）が名簿(JSON)を保持
       → アプリが名簿を取得 → エンドロール描画（時刻順＝早い人ほど大きく）
```
お金は Stripe → 本人の口座。アプリは名簿だけを見る（金には触れない）。

## 段階（無駄に作らない・小さく出す）
- **P1**: 「応援する／コーヒーをおごる」ボタン → Stripe Payment Link を開くだけ（最小）
- **P2**: エンドロール画面（About 内）。名簿JSON（当面は手動・静的）を夜祭りUIで自動スクロール＋ループ
- **P3**: webhook → Worker で名簿を**自動追記**（本当の自動エンドロール）

## 守る線（MVP土台）
- **独立性**: 名簿取得が落ちても本体（付箋）は無傷。遅延取得・キャッシュ・失敗は黙って無視
- **無料**: Stripe（無料・従量手数料のみ）＋ CF Worker 無料枠
- **プライバシー**: 載るのは同意した表示名だけ。金額は非公開。付箋データと完全分離
