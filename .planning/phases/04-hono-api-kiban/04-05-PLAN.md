**Step 1: Vercel 環境変数の設定**

Vercel Dashboard または CLI で以下の環境変数を設定してください:

```
GOOGLE_CLIENT_ID     = Google Cloud Console の OAuth 2.0 クライアント ID
GOOGLE_CLIENT_SECRET = OAuth 2.0 クライアントシークレット
VAPID_PUBLIC_KEY     = npx web-push generate-vapid-keys で生成（Public Key）
VAPID_PRIVATE_KEY    = 同上（Private Key）
API_SECRET           = 任意の文字列（Bearer トークン）
```

Google Cloud Console の設定:
1. Google Drive API を有効化
2. OAuth クライアントの承認済みリダイレクト URI に `https://{vercel-url}/api/v1/auth/callback` を追加

CLI で設定する場合:
```bash
npx vercel env add GOOGLE_CLIENT_ID production
npx vercel env add GOOGLE_CLIENT_SECRET production
npx vercel env add VAPID_PUBLIC_KEY production
npx vercel env add VAPID_PRIVATE_KEY production
npx vercel env add API_SECRET production
```

設定後、再デプロイ:
```bash
npx vercel --prod
```

**Step 2: Google OAuth 認証フロー（初回のみ）**

ブラウザで以下を開く:
```
https://{vercel-url}/api/v1/auth
```

Google アカウントでログイン → 権限を許可。
画面に表示された `refresh_token` をコピーして Vercel 環境変数に登録:
```bash
npx vercel env add GOOGLE_REFRESH_TOKEN production
```
設定後、再デプロイ:
```bash
npx vercel --prod
```

**Step 3: curl で検証**

```bash
export BASE_URL="https://{vercel-url}"
export TOKEN="your-api-secret"

# 認証なし → 401
curl -s -o /dev/null -w "%{http_code}" $BASE_URL/api/v1/notes/latest

# Subscribe（ダミーのPush Subscription）
curl -s -X POST $BASE_URL/api/v1/subscribe \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"endpoint":"https://example.com/push","p256dh":"test","auth":"test"}' \
  -w "\n%{http_code}\n"

# Note push（Push 送信はダミーなので失敗する場合あり）
curl -s -X POST $BASE_URL/api/v1/notes/push \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"テスト","body":"Hello","endpoint":"https://example.com/push","p256dh":"test","auth":"test"}' \
  -w "\n%{http_code}\n"

# Latest note 取得
curl -s $BASE_URL/api/v1/notes/latest \
  -H "Authorization: Bearer $TOKEN" \
  -w "\n%{http_code}\n"
```

**成功の基準:**
- 認証なし → 401
- POST /subscribe → 200（Google Drive に保存確認）
- GET /notes/latest → 200（保存した note が返る）
- POST /notes/push → 200 または 410（Push Subscription がダミーなので 410 は許容）
