実装上の注意:
1. `export const runtime = 'nodejs'` を必ず宣言（googleapis は Edge Runtime 非対応）
2. `import { handle } from 'hono/vercel'` を使用（`@hono/node-server/vercel` ではない — Pitfall 1 回避）
3. `const app = new Hono().basePath('/api/v1')` で basePath を設定（Pitfall 3 回避）
4. Bearer 認証は `app.use('/*', ...)` に適用するが、`/auth` と `/auth/callback` は除外する
   - 除外方法: `app.use('/subscribe', ...)` のように個別適用 OR `/auth` を先にルート登録してから `app.use()` を後から設定
5. エラーハンドリング: try-catch で err.message が 'OAUTH_REFRESH_TOKEN_EXPIRED' / 'OAUTH_NOT_CONFIGURED' なら 503
6. exported: `export const GET = handle(app)` と `export const POST = handle(app)` の両方

/api/v1/auth 実装の詳細:
- `google.auth.OAuth2` を使って authUrl を生成
- scope: `['https://www.googleapis.com/auth/drive.file']`
- GET /api/v1/auth → `c.redirect(authUrl)`
- GET /api/v1/auth/callback → code で `auth.getToken(code)` → refresh_token を HTML で表示
  （セキュリティ: 本番 Vercel では VERCEL_URL 以外からのアクセスは想定しない。シンプルな HTML で十分）

テスト修正が必要な場合（スキャフォールドの import パスが間違っている等）は route.test.ts を修正してよい。
lib/gdrive と lib/webpush は vi.mock でモックする。
