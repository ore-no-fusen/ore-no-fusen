**実装する公開関数:**

1. `pub fn get_vapid_key_path() -> PathBuf`
   - `BaseDirs::new()` で `{data_local_dir}/ore-no-fusen/vapid_keys.json` を返す

2. `pub fn generate_vapid_keys() -> Result<VapidKeys, String>`
   - `p256::ecdsa::SigningKey::random(&mut rand_core::OsRng)` で P-256 秘密鍵生成
   - 公開鍵を非圧縮形式（65 bytes）で取得: `signing_key.verifying_key().to_encoded_point(false)`
   - 両キーを base64url（no padding）でエンコード
   - subject を `"mailto:ore-no-fusen@example.com"` に固定
   - `get_vapid_key_path()` に JSON で保存して返す
   - **rand_core は p256 の依存として間接的に利用可能。ただし明示的に rand_core = "0.6" を Cargo.toml に追加してもよい**

3. `pub fn load_or_generate_vapid_keys() -> Result<VapidKeys, String>`
   - `get_vapid_key_path()` が存在すれば読み込み
   - 存在しなければ `generate_vapid_keys()` を呼んで保存・返却

4. `pub fn sign_vapid_jwt(endpoint: &str, keys: &VapidKeys) -> Result<String, String>`
   - endpoint の origin（scheme + host のみ）を抽出（`https://api.push.apple.com` の形式）
   - claims:
     ```
     aud: endpoint origin
     exp: now + 12 hours (Unix timestamp)
     sub: keys.subject
     ```
   - `URL_SAFE_NO_PAD.decode(&keys.private_key_b64url)` で秘密鍵バイトを取得
   - `ES256KeyPair::from_bytes(&private_key_bytes)` で jwt-simple キーを構築
   - `key_pair.sign(claims)` で JWT 文字列を返す

5. `pub fn encrypt_payload(p256dh_b64url: &str, auth_b64url: &str, plaintext: &[u8]) -> Result<Vec<u8>, String>`
   - RFC 8291 の手順で暗号化:
     1. `URL_SAFE_NO_PAD.decode(p256dh_b64url)` で受信側公開鍵バイト取得
     2. `PublicKey::from_sec1_bytes(&peer_public_key_bytes)` でパース
     3. `EphemeralSecret::random(&mut rand_core::OsRng)` で送信側エフェメラル秘密鍵生成
     4. ECDH shared secret 計算: `ephemeral_secret.diffie_hellman(&peer_public_key)`
     5. ephemeral 公開鍵を非圧縮 65 bytes で取得
     6. auth secret をデコード: `URL_SAFE_NO_PAD.decode(auth_b64url)`
     7. salt = 16 random bytes
     8. HKDF-SHA256 で鍵導出（RFC 8291 の "Content-Encoding: aes128gcm" info strings を使用）
     9. `Aes128Gcm::new(Key::from_slice(&content_encryption_key))` で暗号化
     10. nonce（12 bytes）を HKDF から導出（または salt から生成）
     11. padding + plaintext を暗号化
     12. RFC 8291 のヘッダー（salt + record_size + key_id）を先頭に付けた完全な暗号文バイトを返す
   - **実装が複雑な場合の代替**: RESEARCH.md では `web-push 0.11` の利用も候補。Cargo.toml に `web-push = "0.11"` を追加し `ContentEncoding::Aes128Gcm` を使う選択も可。その場合、この関数の実装は web-push crate のラッパーになる。

6. `pub async fn send_web_push(client: &Client, pro_config: &ProConfig, plaintext_json: &str) -> Result<(), String>`
   - `load_or_generate_vapid_keys()?` で VAPID キーを取得
   - `encrypt_payload(&pro_config.p256dh, &pro_config.auth, plaintext_json.as_bytes())?` で暗号化
   - `sign_vapid_jwt(&pro_config.push_endpoint, &keys)?` で VAPID JWT 生成
   - APNs への POST:
     ```
     POST {pro_config.push_endpoint}
     Content-Type: application/octet-stream
     Content-Encoding: aes128gcm
     TTL: 86400
     Authorization: vapid t={jwt},k={public_key_b64url}
     ```
   - `reqwest::Client` の `request()` で送信
   - レスポンスが 201 Created 以外なら `Err(format!("APNs error: {status}"))`

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_vapid_key_path_returns_ore_no_fusen_dir() {
        let path = get_vapid_key_path();
        assert!(path.to_string_lossy().contains("ore-no-fusen"));
        assert!(path.to_string_lossy().ends_with("vapid_keys.json"));
    }

    #[test]
    fn test_generate_vapid_keys_creates_valid_keypair() {
        let keys = generate_vapid_keys().unwrap();
        let pub_bytes = URL_SAFE_NO_PAD.decode(&keys.public_key_b64url).unwrap();
        let priv_bytes = URL_SAFE_NO_PAD.decode(&keys.private_key_b64url).unwrap();
        assert_eq!(pub_bytes.len(), 65, "Public key must be 65 bytes (uncompressed P-256)");
        assert_eq!(priv_bytes.len(), 32, "Private key must be 32 bytes");
    }

    #[test]
    fn test_sign_vapid_jwt_returns_non_empty() {
        let keys = generate_vapid_keys().unwrap();
        let jwt = sign_vapid_jwt("https://api.push.apple.com/3/device/test", &keys).unwrap();
        assert!(!jwt.is_empty());
        // JWT は 3 つのドット区切りセクションを持つ
        assert_eq!(jwt.split('.').count(), 3);
    }

    #[test]
    fn test_encrypt_payload_returns_non_empty_bytes() {
        // テスト用のダミー P-256 鍵を生成して使用
        let keys = generate_vapid_keys().unwrap();
        // p256dh には有効な 65-byte 公開鍵（uncompressed）が必要
        let pub_bytes = URL_SAFE_NO_PAD.decode(&keys.public_key_b64url).unwrap();
        let p256dh = URL_SAFE_NO_PAD.encode(&pub_bytes);
        // auth は 16 random bytes
        let auth_bytes = vec![0u8; 16];
        let auth = URL_SAFE_NO_PAD.encode(&auth_bytes);
        let result = encrypt_payload(&p256dh, &auth, b"hello world");
        assert!(result.is_ok(), "encrypt_payload failed: {:?}", result.err());
        assert!(!result.unwrap().is_empty());
    }
}
