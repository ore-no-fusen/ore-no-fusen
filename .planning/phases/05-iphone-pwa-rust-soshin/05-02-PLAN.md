<!-- PKCE パターン（RESEARCH.md より） -->
async function generatePKCE() {
  const verifier = crypto.randomUUID().replace(/-/g,'') + crypto.randomUUID().replace(/-/g,'');
  const digest = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(verifier));
  const challenge = btoa(String.fromCharCode(...new Uint8Array(digest)))
    .replace(/\+/g,'-').replace(/\//g,'_').replace(/=/g,'');
  return { verifier, challenge };
}

<!-- urlBase64ToUint8Array ヘルパー（RESEARCH.md より） -->
function urlBase64ToUint8Array(base64String: string): Uint8Array {
  const padding = '='.repeat((4 - base64String.length % 4) % 4);
  const base64 = (base64String + padding).replace(/-/g,'+').replace(/_/g,'/');
  const rawData = window.atob(base64);
  return Uint8Array.from([...rawData].map(c => c.charCodeAt(0)));
}

    1. **非standalone（バナー表示）**
       - `window.matchMedia('(display-mode: standalone)').matches` が false の場合
       - ページ先頭に固定バナー表示:
         - ① Safari の共有アイコン（↑）をタップ
         - ② 「ホーム画面に追加」を選択
       - それ以外の UI は表示しない（"インストール後にセットアップを完了してください"の一文のみ）

    2. **standalone + セットアップ未完了（ステップ表示）**
       - URLに `?code=` パラメータがない場合: ステップ1「Googleでログイン」ボタン表示
         - クリック時: `generatePKCE()` → verifier を sessionStorage に保存 → `startOAuth(challenge)` でリダイレクト
         - redirect_uri: `window.location.origin + '/viewer'`
         - scope: `https://www.googleapis.com/auth/drive.file`
       - URLに `?code=` パラメータがある場合（コールバック）: access_token 取得 → sessionStorage に保存 → ステップ2へ
         - トークンエンドポイント: POST `https://oauth2.googleapis.com/token`
         - パラメータ: code, client_id, redirect_uri, code_verifier（sessionStorageから）, grant_type=authorization_code
       - ステップ2「通知を許可する」ボタン表示
         - クリック時（onClick内で呼ぶこと）:
           1. `Notification.requestPermission()` → 拒否時はエラーメッセージ表示
           2. `navigator.serviceWorker.ready` で SW 待機
           3. `pushManager.subscribe({ userVisibleOnly: true, applicationServerKey: urlBase64ToUint8Array(NEXT_PUBLIC_VAPID_PUBLIC_KEY) })`
           4. `sub.toJSON()` から endpoint + keys を取得
           5. `uploadToDrive(accessToken, 'fusen_push_config.json', { endpoint, keys })` で Drive に保存
           6. 完了状態に遷移

    3. **standalone + セットアップ完了（待機画面）**
       - URLに `?note=` パラメータがある場合: Drive から `fusen_note.json` を fetch して全文表示
         - GET `https://www.googleapis.com/drive/v3/files?q=name='fusen_note.json'+and+trashed=false`
         - ファイルID取得後: GET `https://www.googleapis.com/drive/v3/files/{id}?alt=media`
         - title + body を表示（body は `<pre>` タグでMarkdownテキストとして表示）
       - それ以外: 「PCから付箋が送られたらここに表示されます」のメッセージ

    **スタイリング:** Tailwind CSS を使用。シンプルで読みやすいモバイルファースト。
    - バナー: 黄色背景（bg-yellow-50 border-yellow-200）、アイコン付きテキスト
    - ボタン: bg-blue-600 text-white rounded-lg px-6 py-3、ホバーあり
    - 全文表示: max-w-prose mx-auto px-4、タイトルは text-xl font-bold

    **エラーハンドリング:** 各 fetch/subscribe のエラーを catch して `errorMessage` state に格納し、画面にエラーテキストを表示する（赤字 text-red-600）。
