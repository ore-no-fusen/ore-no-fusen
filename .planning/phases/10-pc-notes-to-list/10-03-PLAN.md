  <name>Task 2: ノンブロッキング送信 UX</name>
  <files>app/viewer/page.tsx</files>
  <action>
    「PCに送る」ボタンの onClick ハンドラを以下のように変更する。

    **現在の構造（ブロッキング）:**
    ```
    setIsLoading(true)
    → トークン確認
    → await 送信処理（5〜10秒）
    → setSendSuccess(true)
    → setIsLoading(false)
    ```

    **変更後の構造（ノンブロッキング）:**

    Step A: ボタン押下時に即座に実行（同期）
    - `const capturedContent = editorRef.current?.innerHTML ?? '';`（内容を保存）
    - `const capturedTags = [...writeTags];`（既存と同名のため確認）
    - エディタをクリア: `if (editorRef.current) editorRef.current.innerHTML = '';`
    - タグをクリア: `setWriteTags([]); setShowTagBar(false); setTagInput('');`
    - 下書き削除: `if (currentDraftId) { deleteDraft(currentDraftId).catch(() => {}); setCurrentDraftId(null); }`
    - バックグラウンド送信状態を立てる: `setIsSendingInBackground(true);`

    Step B: バックグラウンドで送信（await しない / .catch で失敗捕捉）

    ```typescript
    // バックグラウンド送信関数（即実行、await しない）
    (async () => {
      try {
        // トークン確認（既存ロジックをそのまま移動）
        let token = accessToken;
        const expiresAt = parseInt(localStorage.getItem('viewer_expires_at') || '0');
        if (Date.now() > expiresAt - 5 * 60 * 1000) {
          const newToken = await refreshAccessToken();
          if (!newToken) {
            localStorage.removeItem('viewer_access_token');
            localStorage.removeItem('viewer_refresh_token');
            setIsSendingInBackground(false);
            setBackgroundSendError('セッションが切れました。再度ログインしてください。');
            return;
          }
          token = newToken;
          setAccessToken(newToken);
        }
        // 既存の送信処理（Task 1 で並列化済み）
        const rawText = /* capturedContent から getMarkdown 相当で取得 */ ...;
        const { title, body: extractedBody } = extractTitleBody(rawText);
        // ... 画像アップロード・JSON送信・履歴保存 ...
        setIsSendingInBackground(false);
        setBackgroundSendSuccess(true);
        setTimeout(() => setBackgroundSendSuccess(false), 3000);
      } catch (err) {
        setIsSendingInBackground(false);
        const msg = err instanceof Error ? err.message : String(err);
        setBackgroundSendError('送信失敗: ' + msg);
        setTimeout(() => setBackgroundSendError(null), 5000);
      }
    })();
    ```

    **新しい state を追加:**
    ```typescript
    const [isSendingInBackground, setIsSendingInBackground] = useState(false);
    const [backgroundSendSuccess, setBackgroundSendSuccess] = useState(false);
    const [backgroundSendError, setBackgroundSendError] = useState<string | null>(null);
    ```

    **既存の isLoading / sendSuccess / errorMessage はバックグラウンド送信では使わない。**
    ただし既存の変数をそのまま残して壊さないこと。

    **バックグラウンド状態表示 UI（write ステップの最上部またはグローバルに配置）:**
    ```tsx
    {isSendingInBackground && (
      <div className="fixed top-4 right-4 bg-blue-500 text-white text-sm px-3 py-2 rounded shadow z-50">
        送信中...
      </div>
    )}
    {backgroundSendSuccess && (
      <div className="fixed top-4 right-4 bg-green-500 text-white text-sm px-3 py-2 rounded shadow z-50">
        送信しました ✓
      </div>
    )}
    {backgroundSendError && (
      <div className="fixed top-4 right-4 bg-red-500 text-white text-sm px-3 py-2 rounded shadow z-50">
        {backgroundSendError}
      </div>
    )}
    ```

    **「PCに送る」ボタンの disabled 条件:**
    - `disabled={isSendingInBackground}` （バックグラウンド送信中は連打防止）
    - ボタンテキスト: `isSendingInBackground ? '送信中...' : 'PCに送る'`

    **rawText の取得について:**
    現在の onClick 内では `rawText` は `getMarkdown(editorRef.current)` 等で取得している。
    エディタをクリアする前に `const rawText = getMarkdown(editorRef.current);`（または同等）を取得しておくこと。
    `capturedBlobs` も同様にクリア前に `const capturedBlobs = new Map(imageBlobs);` でコピーする。

    実装の際は既存の onClick ハンドラのロジックを注意深く読み、
    「クリア前に必要なデータをすべてキャプチャする」→「UIをクリア」→「バックグラウンド送信」
    の順序を厳守すること。
