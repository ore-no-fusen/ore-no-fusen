# Plan 21-02: 実行時の配布分岐整理

## 目的

Store版を正式版として、更新、自動起動、版表示の実行時分岐と依存を最小化する。

## 作業

1. `distribution.rs`、`lib.rs`、`useUpdateCheck.ts` の配布判定用途を棚卸しする。
2. 本番更新をStore専用にし、Tauri updaterの設定、生成物、UI、依存を安全に除去する。
3. 本番自動起動をStartupTask専用にし、レジストリ方式は非パッケージ開発時だけに限定または除去する。
4. `DisabledByUser` をアプリ内で強制変更せず、Windows設定へ案内する状態表示を維持する。
5. 設定画面とi18nから「お試し版」「通常版」「MSIを入手」を除き、Store版に統一する。
6. package identityなしの開発実行が壊れないことをテストする。

## 検証

- Rust単体テスト: package identity、StartupTask各状態、非パッケージ時fallback。
- UI単体テスト: ON/OFF、DisabledByUser案内、Store版表示。
- 静的確認: updater endpoint、MSI版リンク、trial/standard文言が本番経路に残らない。

## 完了条件

Store版の更新と自動起動が単一仕様になり、開発実行を保ったまま旧配布専用分岐が除去されている。
