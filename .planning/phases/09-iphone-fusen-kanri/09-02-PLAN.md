**変更1: list の li に削除ボタンを追加（下書きのみ）**

各 li の内部、`<div className="flex items-center gap-2 mb-1">` と `<p>` の間に削除ボタンを追加する。
li の flex レイアウトを調整して削除ボタンを右端に配置する。

```tsx
<li
  key={note.id}
  className="px-4 py-3 border-b border-gray-100 cursor-pointer active:bg-gray-50 flex items-center gap-2"
  onClick={async () => { /* Plan 01 で修正済みの onClick をそのまま維持 */ }}
>
  <div className="flex-1 min-w-0">
    <div className="flex items-center gap-2 mb-1">
      <span className={`text-sm font-semibold px-2 py-0.5 rounded ${
        note.status === 'sent' ? 'bg-blue-500 text-white' : 'bg-yellow-400 text-gray-900'
      }`}>
        {note.status === 'sent' ? '送信済み' : '下書き'}
      </span>
      <span className="text-sm text-gray-500">
        {note.created_at ? (() => { try { return formatRelativeTime(note.created_at); } catch { return ''; } })() : ''}
      </span>
    </div>
    <p className="text-sm text-gray-700 truncate">
      {(note.title || note.body).slice(0, 20) || '（空のメモ）'}
    </p>
  </div>
  {note.status === 'draft' && (
    <button
      className="p-2 text-gray-400 hover:text-red-500 flex-shrink-0"
      aria-label="削除"
      onClick={async (e) => {
        e.stopPropagation();
        setIsLoading(true);
        try {
          await deleteDraft(note.id);
          const updated = await loadAllDrafts();
          setHistoryNotes(updated.map((d) => ({ ...d, status: 'draft' as const })));
        } catch {
          // エラー無視（即削除）
        } finally {
          setIsLoading(false);
        }
      }}
    >
      🗑️
    </button>
  )}
</li>
```

`e.stopPropagation()` を必ず呼ぶ（li の onClick への伝播を止める）。
削除ボタンは `note.status === 'draft'` のノートにのみ表示する（sent は IndexedDB 対象外）。
削除後は `setHistoryNotes((prev) => prev.filter(...))` ではなく `loadAllDrafts()` で再取得して setHistoryNotes を更新すること（CONTEXT.md: 「削除後は一覧を再取得」）。

NOTE: `loadAllDrafts()` が返す DraftRecord には `status` フィールドがないため、`map` で `status: 'draft'` を付与する。list 画面では sent ノートも表示される場合は既存の historyNotes ロジックに合わせて merge する。
