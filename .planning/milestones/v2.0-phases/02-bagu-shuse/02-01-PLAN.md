src-tauri/src/logic.rs の L371 を修正する。

**修正内容（1 行）:**

Before:
```rust
let start_idx = content.find("---").unwrap() + 3;
```

After:
```rust
let start_idx = content.find("---").unwrap_or(0) + 3;
```

理由: 関数シグネチャが `-> String` のため `ok()?` 早期リターンは使えない。`unwrap_or(0)` はフォールバック時に既存の `format!("---\n...")` 分岐と同等の挙動になる。呼び出し前の `starts_with("---")` 保護条件（trim_start() 後）があるが、trim_start() なしの find() は先頭空白がある場合に理論上 None になりうるため安全化が必要。

修正後、以下のコマンドでコンパイル確認してからコミット:
```
cargo build --manifest-path src-tauri/Cargo.toml
```
