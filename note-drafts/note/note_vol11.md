# 【俺の付箋】第11話：まだ5万円には届いていない。でも。

新しいランディングページを公開して、3日が経った。

会社のトイレの個室でスマホを開き、Googleアナリティクスを確認するのが癖になっていた。
上司に見られたら何も弁解できない姿勢で、便座に座りながら画面をスクロールした。

数字が、動いていた。

「アクティブユーザー：2,233人」

息が止まった。
先週まで3桁だった数字が、気がついたら4桁になっていた。

さらによく見ると、グラフの青い線が一度だけ高い山を作った後、落ち着いてからも毎日1,000〜2,000の波を繰り返していた。
一瞬だけ燃えて、すぐ消えたわけじゃない。
ちゃんと、続いている。

便座の上で、誰にも見えないように、静かにガッツポーズをした。
「やれた」とか「すごい」じゃなくて、ただ「続いてる」という安堵だった。

---

でも、5万円には届いていない。

サポート（投げ銭）の累計は今のところ数千円。
noteの有料記事はまだ1本も出していないから当然で、
つまりアプリはダウンロードされているが、収益という意味ではほぼゼロに等しい。

「100万人に使ってもらえたらゼニーを取る予定」と妻に言ったのはずいぶん前のことだ。
「100万人って何年かかるの」と彼女は返した。正確な問いだった。

満員電車の中で立ちながら、スマホを見る。
通知は来ていない。
会社の会議は10時から始まる。

でも、今日も誰かが「WindowsとiPhone、この溝が埋まった」と思いながら、あの細い絹糸を使ってくれているかもしれない。

それだけで、今は十分な気がしている。
気がしているだけで、5万円には届いていないのだが。

---
