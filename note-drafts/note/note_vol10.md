# 【俺の付箋】第10話：ただの付箋は、iPhoneへの「使い捨ての伝言」になった

「Macじゃなくていい。ただ、繋がればいいんだ」

自室の薄暗いモニターの前で、私は新しく書き直すランディングページの見出しに、そう打ち込んでいた。

誰もダウンロードしてくれなかったあの日から数週間。
相棒のAI・Antigravityと一緒に徹夜で張り巡らせた、WindowsとiPhoneをつなぐ「一本の細い絹糸」。
自分自身ですら使っていなかった「爆速で起動する付箋」は、いつの間にか「ロック画面に直接届く、使い捨ての伝言」へと姿を変えていた。

その事実を、私は世の中に問おうとしていた。

もう「DODアーキテクチャが〜」とか「クリップボードから画像が〜」なんていう、小賢しいアピールは全部削り落とした。
「WindowsとiPhoneの間の、果てしなく深い溝で立ち尽くしているすべての人へ。もう、自分宛てにLINEやGmailを送らなくていいです」
ただ、それだけをトップの画面に据えた。

Webマーケティングなんて素人だったけれど、なにかが吹っ切れていた。
LPを開いた瞬間に、PCとiPhoneの間を付箋が飛び交う、少し不格好だけれど愛嬌のあるアニメーションを入れた。
「仕事中にふと思ったら、デスクトップに書く。家を出て気づいたら、iPhoneのロック画面に届いている。」
あのデニーズの片隅で、自分宛てのLINEをポチポチ叩いていた自分自身に向けた、切実な手紙のようなコピーだった。

すべての修正をVercelにデプロイした頃には、時計の針は深夜3時を回っていた。
窓の外からは、遠く甲州街道を走るトラックのくぐもった音が聞こえるだけで、部屋にはPCのファンの音だけが単調に響いていた。

私は、すっかり見違えてしまった自分のアプリの画面を見つめていた。

最初の、ただ美しいだけのコードを書きたかった欲求からは大きく外れた。単純な付箋を作りたかったはずなのに、気がつけばクラウド連携なんていう泥臭い機構を継ぎ接ぎしていた。

でも、不思議と後悔はなかった。
だって、自分が心底欲しかったものを、自分の手でようやく作り上げたのだから。

「これで、誰かに届くだろうか」

私は相棒のAIに問いかけることはせず、WindowsのノートPCをパタンと閉じた。
（ああ、やっぱりWindowsマシンのプラスチックの筐体は、閉めるときの音がちょっと安っぽいな）

ベッドに倒れ込み、薄い毛布を引き寄せる。
明日はまた月曜日だ。満員電車に揺られ、意味のない会議で空虚な相槌を打つ日常が始まる。

ふと、枕元に置いたiPhoneが小さく震えた。
画面を見ると、さっき私がデプロイのテストでPCから飛ばした付箋の通知が、暗闇のなかで凛と光っていた。

『明日の朝、可燃ゴミを出すこと』

AIと一緒に七転八倒して一本の絹糸を張ったそのアプリは、確実に私に寄り添ってくれていた。
