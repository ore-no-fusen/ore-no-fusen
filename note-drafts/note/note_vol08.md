# 【俺の付箋】第8話：深夜の自室で、自分への嘘に気づいた話

深夜１時半のデスクで、冷めきったコーヒーを見つめていた。

PCの画面には、私が作ったアプリのダウンロード数が表示されている。
「255」。
確かに数字は少しずつ増えている。だが、私が目指しているのは「100万ダウンロード」だ。
100万という果てしない目標から見れば、255なんて立ち止まっているのと同じだった。

15年ぶりにコードを書いた。AIという相棒のおかげで、自分でも驚くほどサクサクと「俺の付箋」というアプリが完成した。
0.5秒で起動するし、クリップボードの画像をそのままペーストして、赤ペンで直接マークもできる。PCを開くたびに、「うん、俺の求めていたものがいちばん上手くできた」と自画自賛していた。

それでもやはり、実際に定着している気配はまったくなかった。
スキも、コメントも、レビューもゼロ。
ただダウンロードされて、一瞬だけ開かれて、そして静かにアンインストールされているのだ。
世の中のどこを探しても、私の作ったこのアプリを「毎日必要としている人」なんて、最初からいなかったのかもしれない。

ため息をついて、薄暗い部屋の天井を目で追った。
ふと、明日の会議で使えるかもしれないアイデアが浮かんだ。忘れないうちにメモしておこうと思った私は、机の上に置いてあるiPhoneを習慣のように手に取っていた。

いつものようにポケットからiPhoneを取り出し、標準の「メモ」アプリにフリック入力でアイデアを打ち込んだ。

——ふと、嫌なことに気づいてしまった。

私の目の前には、フルサイズのキーボードがあり、画面には魂を込めて作った「爆速で起動する最強のPC付箋」が開かれたままになっている。
なのに私は、今、わざわざ小さなスマホの画面をポチポチと叩いていた。

なぜか。
「自宅のWindows PCにメモを書いても、明日の自分には届かないから」だ。

明日の朝、私は家を出て電車に乗り、会社へ行く。会社のPCは別の端末だ。
もし今、目の前の自分のアプリにメモを書いたとしても、それはこの自宅のPCの中に幽閉されてしまう。家を出た瞬間に見直す手段がない。

だから結局、物理的に持ち歩く「iPhone」の中に閉じ込めるしかなかった。

私は、アプリのダウンロード数がゼロであることに落ち込んでいたけれど、それ以前の問題だった。
PCの前に座っている自分すら使っていないのだ。

なんてダサいんだろう、と心底思った。

「世の中の不便を解消する最強の付箋を作った」なんて息巻いていたけれど、私自身が抱えている「iPhoneとWindowsの間の、果てしなく深い溝」すら埋められていなかったのだから。

MacとiPhoneを使っているスマートな人たちは、クラウドでシームレスにメモが同期されているらしい。でも、昔からWindowsしか使ってこなかった、そしてスマホだけはiPhoneを使っている私のような中途半端な人間は、いつもこの「分断」の前で立ち尽くしていた。

誰も使わない理由が、わかった気がした。
私でさえ、本当に欲しいものじゃなかったのだ。

「……やり直そう」

冷めきったコーヒーを飲み干して、私はPCをシャットダウンした。
少しだけ窓を開けると、深夜の冷たい春の風が部屋に入ってきた。
