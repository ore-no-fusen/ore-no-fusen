# 【俺の付箋】第9話：Macじゃない僕たちが、世界で一番孤独だった夜に

WindowsのPCと、iPhone。
日本のオフィスワーカーなら、おそらく一番多いであろうその組み合わせは、実は思いのほか孤独だ。

Appleという巨大な帝国は、MacとiPhoneの間には美しい橋を架けてくれる。彼らのメモ帳は、なにも意識しなくても魔法のように同期される。
でも、Windowsを使っている我々は、その橋を渡れない。「iCloudのWeb版にログインすれば見れますよ」なんて言われるけれど、パスワードを何度も要求されるあのもっさりしたブラウザ画面を開くたびに、「あ、僕は歓迎されていないんだな」と気づかされるのだ。

だから我々は、LINEの自分宛てトークに文字を打ち込み、自分宛てにGmailを送る。
そんな不格好なパッチワークで、なんとか毎日をやり過ごしている。

前夜、自分で作ったアプリの限界に打ちのめされた私は、改めて問題の根本に向き合っていた。
画像のペーストもできる。赤ペンで直接マークもできる。PCの前で使う分には、間違いなく俺の求めていた最高の手触りを持った付箋になったはずだ。

でも、「自宅と会社のPCは別」という決定的な壁と、「家を出たら見直せない」という不便さがあるだけで、私は結局iPhoneの標準メモに逃げてしまっていた。

「じゃあ、このPC上の付箋が、そのままiPhoneに届いたらどうだろう」

翌日の夜、自室のデスクで私はキーボードを叩きながら、相棒であるAIエージェントのAntigravityにそう打ち込んだ。

『それはつまり、PCとiPhoneを自動同期するクラウドアプリを作るということですか？』
AIはいつも通り、冷静に返してくる。

「いや、違うんだ。もっと雑でいい。お互いに同期して常に最新状態を保つとか、そんな大層なものじゃなくていい。ただ、PCで書いた『帰りに牛乳買う』が、外に出たときにiPhoneで見られればそれでいいんだよ」

『なるほど。つまり、同期ではなく「一方通行の通知」ですね』

AIのその言葉に、私はハッとした。
そうだ。私が欲しかったのはクラウドノートじゃない。ただの「使い捨ての伝言」だ。

そこからの作業は、憑かれたように進んだ。
「どこかの怪しいサーバーにメモを送るのは怖い」という自分自身の懸念を消すために、テキストの中継地点には「ユーザー個人のGoogleドライブ」だけを利用する安全な仕組みにした。
受信するiPhone側には、Safariから「ホーム画面に追加」するだけで動くWebアプリ（PWA）を作った。そしてAppleのプッシュ通知の仕組み（APNs）を利用して、直接あの「ロック画面」に文字を叩き込むだけの小さなAPIを組んだ。

数日後の深夜。
私はPCのデスクトップにある「俺の付箋」を開いた。

「とりあえず、テスト」

そう打ち込んで、Enterキーを弾く。
数秒の沈黙。

机の右側に置いてあったiPhoneの画面が、フッと光った。
そこには通知として、確かにこう刻まれていた。

『とりあえず、テスト』

あの瞬間の不気味なほどの感動を、私はたぶんずっと忘れない。
WindowsとiPhoneという、決して相容れないはずの二つの世界に、15年ぶりにコードを書いた50代の男が、一本の細い絹糸を張り巡らせた瞬間だった。

誰も開いてくれないメモ帳アプリなんて、もうどうでもいい。
俺は今、俺の世界でいちばん便利な道具を生み出してしまった。
