# 15年ぶりにコードを書いたら、全部できた。なのに0円だった話

---

## まず正直に言います

稼げていません。

この連載は「AIエージェントと一緒に、5万円稼ぐまで」を記録するものです。
でも今この瞬間、収益はゼロです。

ゼロから書き始めます。

---

## 自己紹介

50代、現役システムエンジニアです。

「エンジニアなら当然コードが書けるでしょ」と思われそうですが、実態はちょっと違います。

仕事はどちらかというとコンサルに近い——と言うと聞こえはいいですが、実際は**なんでもやる調整屋**です。リーダーのサポート、関係者との折衝、話が決まらない会議の交通整理、成果の刈り取り代行。要するに雑用係です。コードを書く仕事ではありません。

最後にコードを書いたのは、**15年ほど前**です。

ちょうどC言語からJavaに移り変わった時代で、「これからはオブジェクト指向だ！」と言われながら書いていました。あの頃の熱量を、なんとなく覚えています。

そんな私が去年の12月、AIエージェントというものと出会いました。

---

## 出会い

Antigravityというツールです。Googleが作ったAIエージェントで、無料で使えます。

どんな存在かというと——

**東大出身なんだけど、会社には初日で、コードのこと以外は何もわからなくて、日本語もちょっと不自由な新人。**

そんな感じです。

頭は恐ろしくいい。コードを書かせたら超一流。でも「この会社の昨日の経緯」とか「おれの好み」とかは何も知らない。というか、**すぐ忘れる。おじいちゃんです。** 30分もしてセッションが変わったら、もうすっかり忘れています。毎朝「はじめまして」から始まります。

試しに「Windowsで動く付箋アプリを作ってほしい」と頼んだら、翌日には動くものができていました。

私が何をしたかというと、**「これを作って」と言っただけです。**

……というのは少し盛っていて、実際にはあれやこれや、いろいろいろいろ、たくさんのお願いが必要でした。でも、コードは一行も自分で書いていません。

---

## なんで付箋アプリ？

自分が欲しかったから、です。

SE仕事でメモを取るとき、私はExcelを使っていました。理由はシンプルで、**スクリーンショットを頻繁に貼るから**です。打ち合わせ中に画面をキャプチャして、そのままペタッと貼れるのはExcelくらいしかなかった。

**でもExcelが遅い。**

起動している間に、メモしたいことを忘れます。

画像も貼れて、すぐ起動して、箇条書きやチェックボックスも使える——そんなものが欲しかった。どこを探してもなかったので、自分で作ることにしました。

**「Ctrl+Nを押したら0.5秒で書き始められる付箋」**

これが最初の要件でした。

---

## 3ヶ月でできたこと

動くアプリが完成し、GitHubで公開し、Windowsの公式パッケージマネージャー（winget）に登録しました。

```
winget install ore-no-fusen
```

これが打てるようになったとき、正直ちょっと泣きそうでした。15年前の自分には想像もできないことです。

そして——

**「できなかったこと」が、正直ほぼありませんでした。**

画像のペーストも、Markdownも、検索も、タグ管理も、iPhoneへの通知連携も。最初に「欲しい」と思い描いた機能は、ほぼすべて形になりました。

AIエージェントというものの力に、今でも少し驚いています。

---

## 現実

ダウンロード数は **21** です（2026年3月時点）。

収益は **0円** です。

「全部できた」のに、**0円**。

作れることと、売れることは、まったく別の話でした。私はそれを、作り終えてから初めて知りました。

ちなみに以前は44ダウンロードまで積み上げていたのですが、iPhone連携機能の追加で再リリースしたらカウントがリセットされて21になりました。頑張って積み上げた数字が一瞬で消えた瞬間は、わりと笑えませんでした。

でも——21人は、インターネットの向こうの知らない誰かが「これ試してみよう」と思ってくれた数です。最初はゼロだった。0が1になった日のことは、今でも覚えています。

---

## この連載について

月2万円を稼ぐまで、書き続けます。

最初は5万円を目標にしていましたが、よく考えたら月2万でいいや、と思い直しました。それでもダメなら、近くにできた丸亀製麺で次男と一緒にバイトでもするかな、という感じです。

どうやって稼ぐかは、正直まだわかっていません。アプリの有料機能なのか、この記事なのか、全部同時に探りながら進みます。

うまくいかない話も、ぜんぶ書きます。

同じことを考えている人に、少しでも届けばと思っています。
