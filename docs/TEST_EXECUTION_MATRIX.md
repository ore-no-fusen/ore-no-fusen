# 開発工程と検査の一覧

2026-10-27。**要求を整理し、設計書を作ってから、画面・内部処理を作り、機能・性能を確認してリリースへ進む順序**を大項目にしました。画面・Rust等は各工程の中分類です。

## 読み方

T01が開発工程の大項目、T01-01がその工程内の作業・検査です。「工程作業」は要求・設計・実装などの作成作業で、「既存検査」は従来の45実行単位です。**15の工程作業を説明欄として加えましたが、自動テストを15件増やしたわけではありません。** 個別237ファイルは [機能別索引](TEST_FILE_INDEX.md) から探せます。

小さい修正では既存の要求・設計を確認し、必要部分だけ更新します。T03とT04は行き来し、T05の検査はその途中からも使います。検査に失敗したら要求・設計・実装の該当箇所へ戻ります。CI設定や実際のリリース手順を今回変更したものではありません。正式リリースの正本は [010_RELEASE.md](010_RELEASE.md)、通常統合は [CI_MERGE_POLICY.md](CI_MERGE_POLICY.md) です。
