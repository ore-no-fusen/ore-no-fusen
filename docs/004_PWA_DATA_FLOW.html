🔄 3. write / list 画面 — 何を読んで何に書くか

✏️ write 画面（メモ編集）

  • 読む：IndexedDB loadDraft(id)
  • 書く：IndexedDB saveDraft()
  • タイミング①：バックグラウンドに移行したとき
  • タイミング②：「一覧」ボタンを押したとき
  • タイミング③：3秒自動保存タイマー
  • PCに送る：Drive に書き込み → IndexedDB 削除

📋 list 画面（一覧）

  • 読む：IndexedDB loadAllDrafts()
  • 削除：IndexedDB deleteDraft(id)
  • 🔔 ON：Service Worker で通知を表示
  • 🔔 OFF：Service Worker で通知を閉じる
  • フォールバック（Push 未着時のみ）：Drive の notes_to_iphone.json を読んで IndexedDB に補完 → Drive を削除

🗄️ 5. IndexedDB に保存されるメモの形（DraftRecord）
📦 DraftRecord（1件分）
id 一意キー

locked? 🔒 ロック中フラグ

メモの種類（statusで判断）
✏️ draft（下書き）
sent_at なし・received_pc なし
→ iPhoneで書いて保存中
📥 received_pc（PC受信）
received_pc = true
→ PCから届いたメモ
📤 sent（送信済み）
sent_at あり
→ iPhoneからPCに送ったメモ

↕
🔕 ボタン OFF / 削除
IndexedDB: locked = false
SW: CLOSE_NOTIFICATION 送信
📤 6. PC → iPhone 書き込みフロー（3ケース）

PC アプリは必ず ① Drive に notes_to_iphone.json を書いてから ② APNs Push を送る。 Drive はフォールバック用キュー（Push が届かなかった場合の補完）。処理済みは即削除する。
