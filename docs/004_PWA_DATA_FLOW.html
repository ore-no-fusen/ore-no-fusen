🔄 3. write / list 画面 — 何を読んで何に書くか

✏️ write 画面（メモ編集）

  • 読む：IndexedDB loadDraft(id)
  • 書く：IndexedDB saveDraft()
  • タイミング①：バックグラウンドに移行したとき
  • タイミング②：「一覧」ボタンを押したとき
  • タイミング③：3秒自動保存タイマー

📋 list 画面（一覧）

  • 読む：IndexedDB loadAllDrafts()
  • 削除：IndexedDB deleteDraft(id)
  • 🔔 ON：Service Worker で通知を表示
  • 🔔 OFF：Service Worker で通知を閉じる
  • PCに送る：Drive に書き込み → IndexedDB 削除

🗄️ 5. IndexedDB に保存されるメモの形（DraftRecord）
📦 DraftRecord（1件分）
id 一意キー
title タイトル
body 本文（Markdown）
created_at 作成日時
images[] 添付画像
tags[] タグ
locked? 🔒 ロック中フラグ
received_pc? PC受信フラグ
sent_at? PC送信日時
メモの種類（statusで判断）
✏️ draft（下書き）
sent_at なし・received_pc なし
→ iPhoneで書いて保存中
📥 received_pc（PC受信）
received_pc = true
→ PCから届いたメモ
📤 sent（送信済み）
sent_at あり
→ iPhoneからPCに送ったメモ
🔒 locked フラグの動き
🔔 ボタン ON
IndexedDB: locked = true
SW: showNotification() 実行
↕
🔕 ボタン OFF / 削除
IndexedDB: locked = false
SW: CLOSE_NOTIFICATION 送信
