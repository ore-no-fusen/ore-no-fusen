📱 Viewer 画面定義書

iPhone向け /viewer の全画面・用語・遷移の定義。この文書を会話の共通認識とする。

用語定義
用語定義
PWA iPhoneのホーム画面に追加したアイコンから起動するWebアプリ。URLバーがなくネイティブアプリのように見える。Safari で開いた状態はPWAではない。
ServiceWorker こっちで開発したコード（worker/index.js）。ブラウザのバックグラウンドで動く。アプリが閉じていても動く。

プッシュ通知はAppleのサーバ（APNs）が関係するが、役割分担は以下の通り：
PC → Vercel API → APNs（Appleサーバ）→ iPhoneのOS → ServiceWorker

APNsは「iPhoneを起こす」だけ。起きた後に何をするか（Driveから画像ダウンロード・IndexedDBへ保存・通知表示）はすべてこのServiceWorkerに書いてある。
ロックだぜ ノートをiPhoneのロック画面に通知として表示し続ける機能。一覧画面の🔔ボタンでON/OFF。IndexedDB の locked: true フラグで管理。
step page.tsx 内の React state変数。現在表示する画面を決める。値は banner / login / push / list / write の5種類。
banner SafariでURLを直接開いたときに表示するインストール案内画面。PWAではない。ホーム画面への追加手順を表示する。
※ skipWaiting 導入済みのため、バージョンアップ目的で開く必要はなくなった。
アクセストークン Google APIを呼ぶための認証情報。localStorage の viewer_access_token に保存。有効期限（viewer_expires_at）を過ぎると再ログインが必要。
pending_open ServiceWorkerがプッシュ受信時に IndexedDB（fusen-meta）へ記録するノートID。iOSで通知タップが発火しない場合の補完手段。次回起動時に読み取り、対象ノートをwriteで開く。
