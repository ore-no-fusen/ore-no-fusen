# 利用者向け公開資料の分離（6.1.0準備）

公開先は `https://ore-no-fusen.github.io/ore-no-fusen-guide/`。
開発リポジトリの `public-guide/` をユーザー向け原稿と素材の正本とし、
公開用リポジトリ `ore-no-fusen/ore-no-fusen-guide` には許可したファイルだけを反映する。
アプリとLPのリンクは `lib/public-links.ts` で管理する。

## 更新手順

1. 開発用の独立ブランチで `public-guide/` の対象原稿を修正する。
2. 新規ファイルが必要な場合だけ `publish-files.json` へ追加し、公開対象か確認する。
3. `npm --prefix public-guide ci` と `npm --prefix public-guide run build` を実行する。
   ビルド時にページ内リンク、検索等への開発資料の混入、公開ファイル一覧を検査する。
4. `node scripts/export-public-guide.mjs <空の作業フォルダー>` で公開分だけ書き出す。
   既存ファイルを上書きする出力先や、リンクになっている出力先は使わない。
5. 公開用リポジトリの独立ブランチへ、書き出したファイルの差分だけを反映する。
   削除が必要な場合は対象を個別確認する。開発ブランチのmerge、mirror push、
   `docs-v2/` 全体や `.git` のコピーは行わない。
6. 公開PRで、公開ガイドのbuildと検査の成功を確認してからmainへ統合する。
   Pagesの配信成功、未ログインでの日英ガイド・漫画・規約表示を確認する。
7. 元の開発用変更も通常のPR/全CI成功経路でdevelopへ統合する。

## 公開範囲

日英マニュアル、漫画、FAQ、更新情報、問い合わせ案内、プライバシーポリシー、
利用規約、ライセンス表示と、それらの表示に必要な画像・公開用ビルド設定のみ。
内部設計書、アプリのコード、会員データ、秘密鍵、管理ログ、開発履歴は含めない。
設計書はナビだけでなく、HTML・検索索引・静的添付にも含めない。

## 段階移行

6.1.0でアプリ/LPの導線を新公開先へ切り替える。現在の開発リポジトリと旧Pages、
旧Release資産は今回削除しない。ソース・設計書をユーザーへ案内しない方針へ変更するが、
現リポジトリは猶予期間中は公開のため、直接アクセスできなくなったとは説明しない。

6.1.0のStore公開後およそ3か月を目安に、6.2/7等の区切りで現リポジトリの非公開化を判断する。
自動切替ではなく、旧リンクの残影響、Vercelのprivate権限、CI利用枠、Git認証を確認してから行う。
旧MSI/NSIS版の移行経路は非公開化後も維持する要件から外す。既存の付箋やStore製品IDは変えない。
無料privateではGitHub側のCI必須強制が使えないため、最新head/baseの全CI成功を運用で確認する。

本作業は6.1.0の準備であり、Store提出・main統合・公開設定変更は別途の正式手順に従う。
