# 困ったときに

症状から確認してください。

## 症状別

| 症状 | まず確認 |
|---|---|
| 付箋が表示されない | トレイアイコン、データ保存場所 |
| データが消えたように見える | `.md` ファイル、`.trash/` |
| 起動しない | タスクマネージャー、再起動 |
| 検索できない | アプリ再起動 |
| アラームが鳴らない | 効果音、Windows音量 |
| iPhoneに届かない | Google再認証、通信状態 |

::: caution
データを消す操作の前に、保存フォルダをコピーしてバックアップしてください。
:::

## データ保存場所

```txt
C:\Users\[ユーザー名]\AppData\Roaming\ore-no-fusen
```

削除した付箋はOSのごみ箱、または `.trash/` に残る場合があります。
