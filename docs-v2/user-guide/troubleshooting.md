# 困ったときに

まずはデータを守ってから、症状に近い項目を確認してください。

::: warning
削除、再インストール、保存場所の変更をする前に、保存フォルダを丸ごとコピーしてバックアップしてください。
:::

## まず確認すること

| 確認 | 見る場所 |
|---|---|
| アプリが起動しているか | Windowsのタスクバー右下、またはタスクマネージャー |
| 保存フォルダがあるか | 初期値は `C:\Users\[ユーザー名]\Documents\OreNoFusen`。設定で変更した場合は、その保存先 |
| 付箋ファイルが残っているか | 保存フォルダ内の `.md` ファイル |
| 削除済みデータが残っているか | OSのごみ箱、または保存フォルダ内の `.trash/` |

## 付箋が表示されない

1. Windowsのタスクバー右下に「俺の付箋」のアイコンがあるか確認します。
2. アイコンがある場合は、右クリックメニューから付箋を表示できるか確認します。
3. アイコンがない場合は、スタートメニューから「俺の付箋」を起動します。
4. それでも出ない場合は、保存フォルダに `.md` ファイルが残っているか確認します。

## 起動しない

1. タスクマネージャーを開きます。
2. `ore-no-fusen` が残っていたら終了します。
3. もう一度スタートメニューから起動します。
4. 改善しない場合は、PCを再起動してからもう一度起動します。

## データが消えたように見える

まず保存フォルダをコピーしてから確認してください。初期値は次の場所です。

```txt
C:\Users\[ユーザー名]\Documents\OreNoFusen
```

設定で保存場所を変更している場合は、設定画面で選んだフォルダを確認してください。

| 探すもの | 意味 |
|---|---|
| `.md` ファイル | 通常の付箋データ |
| `.trash/` | アプリ内で削除した付箋が残る場合がある場所 |
| OSのごみ箱 | Windows側で削除された場合に残る場所 |

## 検索できない

1. 付箋を保存してからアプリを再起動します。
2. 検索したい文字が別の付箋に入っているか確認します。
3. 直らない場合は、保存フォルダに `.md` ファイルが残っているか確認します。

## アラームが鳴らない

1. アプリ設定で効果音がオンか確認します。
2. Windowsの音量がミュートになっていないか確認します。
3. Bluetoothイヤホンなど、別の出力先に音が出ていないか確認します。

## iPhoneから届かない

1. PC側でGoogle連携が有効か確認します。
2. iPhone側で送信後、通信状態が安定しているか確認します。
3. PC側のアプリを起動したまま、少し待ってから再確認します。
4. 改善しない場合は、PC側でGoogle再認証を行います。

## それでも直らない場合

次の情報を控えてから、GitHub Issues またはサポート窓口に送ってください。

| 情報 | 例 |
|---|---|
| 何が起きたか | 付箋が表示されない、iPhoneから届かない |
| 直前にした操作 | 再インストールした、保存場所を変えた |
| Windowsの状態 | 再起動後も同じ、タスクトレイにアイコンあり |
| 保存フォルダの状態 | `.md` はある、`.trash/` は空 |
