# くわしい使い方

表、図、画像、アラーム、整列で付箋を作業台として使えます。

## 機能早見表

| 機能 | 使いどころ |
|---|---|
| テーブル | 比較、一覧、チェック表 |
| Mermaid | 流れや関係を図にする |
| 画像 | エラー画面、手順、資料 |
| アラーム | 時刻で思い出す |
| 文字サイズ | 重要度に合わせて見た目を変える |
| タグ整列 | 散らかった付箋を並べる |

## タグごとの整列

トレイメニューの **タグで整列** で、タグごとに付箋を並べられます。

![カンバン整列の基本セット](/arrange/arrange-basic.png)

> 整列はメインディスプレイに集約されます。

## ショートカット

| キー | 機能 |
|---|---|
| `Ctrl+N` | 新しい付箋 |
| `Ctrl+F` | 検索 |
| `Ctrl+Shift+H` | 全付箋を隠す / 戻す |
| `Ctrl+Shift+L` | タグで整列 |
