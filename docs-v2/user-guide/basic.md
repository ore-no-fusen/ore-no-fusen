## 最短操作

| やりたいこと | 操作 |
|---|---|
| 新しい付箋 | `Ctrl+N` またはトレイ右クリック |
| 編集 | 付箋をダブルクリック |
| 編集終了 | 外側クリック、または `Esc` |
| 検索 | `Ctrl+F` |
| 削除 | 付箋右側のごみ箱、または右クリック → 削除 |

::: tip
付箋上で `Ctrl+N` を押すと、右隣に新しい付箋が出ます。
:::

## 書き方

テキスト選択時のフォーマットバーで、太字・見出し・箇条書き・チェックボックス・表・画像を入れられます。

```markdown
# 今日やること
- [ ] メールを見る
- [ ] 見積もりを送る
```

## 手前に表示する・小さくする

付箋右上の画びょうボタンを押すと、他のアプリより手前に表示されます。赤い画びょうが固定中の目印です。もう一度押すと解除できます。右上の **△** は付箋全体を小さくし、**▽** で元の大きさに戻します。

## 整理する

- `#仕事` のようにタグを書く
- 付箋のタグを押すと、そのタグフォルダを開けます
- `Ctrl+F` で全文検索
- デスクトップから片付けたい付箋は、右側の箱ボタンで「しまう」

上部には新規追加・たたむ・ピン留め、右側には少し離して「しまう」と「削除」があります。右下は付箋の大きさを変える場所です。

::: tip ランチャー登録とタグは別のものです
「ランチャーに登録」はクイックランチャーへの近道を作る操作で、分類タグを追加する操作ではありません。ランチャーに登録しても `shortcut` という内部名はタグとして表示されず、タグ整列やしまう先にも使われません。

タグで整列すると、開いているレシピ・QA・用語は「未分類」としてタグなし置き場へまとまります。閉じている結晶が整列によって開くことはありません。
:::

### しばらく使わない付箋をフォルダーに保管する

右クリックの「タグフォルダへしまう」は、付箋をタグフォルダへ保存し、デスクトップから消す操作です。タグがない付箋はアーカイブへ、タグが1つならそのタグへしまいます。複数タグがある場合は、ボタンを押した後にしまう先を選びます。

取り出すときは、トレイアイコンを右クリック → **しまった付箋を取り出す** を開きます。付箋を選んで **○枚を取り出す** を押すと、元の位置と大きさでデスクトップへ戻ります。

データ管理の **Markdownのインポート＆しまったタグのインポート** は、元ファイルを残してコピーする別の操作です。外部のMarkdownを取り込みたい場合や、しまった付箋のコピーが必要な場合に使います。

## クイックランチャー {#quick-launcher}

よく使う付箋を登録して、必要なときにすぐ開けます。デスクトップを片付けたいときはランチャーへ格納し、あとで取り出せます。

### 開く

初期設定は **Ctrl+P**。トレイアイコンやタスクバーのアプリアイコンを右クリック → **クイックランチャーを開く** でも開けます。キーは **設定 → ホットキー → クイックランチャートリガー** で変更できます。「右クリック3連打でも開く」をオンにすると、他のアプリの上でも開けます。

### 登録・しまう・取り出す

| やりたいこと | 操作 |
|---|---|
| 付箋を登録する | 付箋を右クリック → **ランチャーに登録**。**ランチャー**タブの登録一覧に追加されます。登録だけでは付箋は隠れません。 |
| 探して開く | 名前・タグの検索やタグの絞り込みを使い、行をクリック。**↑ / ↓** で選んで **Enter** でも開けます。QA・用語集・手順はそれぞれのタブから開けます。 |
| 1枚しまう | 付箋の行の **格納**。デスクトップから隠れますが、本文や登録は残ります。 |
| 取り出す | 行の **取り出す**、または付箋の行をクリック。デスクトップへ戻っても **登録一覧** には残ります。**格納した付箋** は隠れている分だけの表示なので、取り出すとそこからは外れます。 |
| タグごと登録する | ユーザータグを右クリック → **このタグをまとめて登録**。画面の表示状態は変えません。 |
| タグごとしまう | ユーザータグを右クリック → **このタグをまとめて格納**。ランチャー未登録や文字検索の表示外も含め、同じタグのデスクトップ付箋を、未登録分もまとめて登録したうえで格納します。 |
| 登録を解除する | 行を右クリック → **ランチャーの登録を解除**。付箋は削除されません。格納中なら先に取り出されます。 |

::: tip ランチャー格納とフォルダー収納
ランチャーの「格納」はファイルを移動せずに付箋を隠します。従来の「タグフォルダへしまう」は保存場所を移す操作です。フォルダーへしまった付箋は、トレイの「しまった付箋を取り出す」から戻します。
:::

## 付箋からアプリ全体を操作する

閲覧中の付箋を右クリックし、**⚙️ アプリ操作**を開くと、次の操作をその場で実行できます。

- 検索
- タグで整列
- 整列を元に戻す
- 設定を開く

付箋そのものに対する色変更、タグ、しまう、削除などの操作とは分けて表示されます。
