# iPhone連携

iPhoneで書いたメモ、画像、動画をPCの付箋として送れます。

## 仕組み

| 項目 | 内容 |
|---|---|
| 中継 | ユーザー自身のGoogle Drive |
| PC受信 | 自動で新規付箋として開く |
| 画像・動画 | PC側へ保存後、中継データは削除 |

::: tip
開発者のサーバーに付箋本文を保存する方式ではありません。
:::

## 初回セットアップ

1. PC側の設定を開く
2. iPhone連携タブでGoogle連携を開始
3. ブラウザで許可
4. 表示されたURLをiPhoneで開く

## 送る

1. iPhone側ページを開く
2. 本文を書く
3. 必要なら画像・動画を添付
4. **PCに送る** を押す

届かない時: [困ったときに](./troubleshooting)
