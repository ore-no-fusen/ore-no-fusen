# Web版とiPhone版の機能比較

Web＝共有画面 ／ iPhone＝ホーム画面アプリ

**○ できる　△ 条件あり　× 未対応**

<p class="table-caption">表15-1　Web版とiPhone版の機能比較（2026-11-16）</p>

| 機能 | Web | iPhone | △ の条件 |
|---|:---:|:---:|---|
| PCの付箋を読む | ○ | ○ | — |
| 本文を編集 | ○ | ○ | — |
| 編集をPCへ反映 | △ | △ | Web：手動同期／iPhone：PCで確認 |
| 新規メモを作る | ○ | ○ | — |
| 画像を見る | ○ | ○ | — |
| 画像を添付してPCへ送る | × | ○ | — |
| 動画を添付してPCへ送る | × | ○ | — |
| 付箋から動画を再生 | × | △ | 対応版で端末保存した動画 |
| PCからの通知を受ける | × | △ | 端末の通知設定が必要 |

旧履歴の動画は復元不可。保存容量は端末による。
