# Troubleshooting

[日本語](/user-guide/troubleshooting)

::: warning
Before uninstalling, changing the data location, or attempting recovery, copy the entire data folder as a backup.
:::

The default data folder is:

```txt
C:\Users\[user name]\Documents\OreNoFusen
```

## Notes are not visible

1. Check the Windows system tray or Task Manager for Ore No Fusen.
2. If it is running, use the tray menu to restore notes.
3. Otherwise launch it from the Start menu or **Ore No Fusen (Store Version)** shortcut.
4. Confirm that `.md` files remain in the data folder.

## Data appears to be missing

Look for normal `.md` files and the `Trash` folder. Deleted crystals are stored under `Recipes/Trash`, `QA/Trash`, or `Terms/Trash`. If you selected a custom data location, inspect that folder instead of the default.

## iPhone items do not arrive

Confirm that Google connection is enabled, both devices use the same Google account, and all setup steps show check marks. Keep the PC app open, refresh the connection status, and reconnect Google if necessary.

## Contact support

Use **Feedback** or **Developer Messages** in Settings. Include what happened, the preceding action, Windows state, and whether the data folder still contains `.md` files.
