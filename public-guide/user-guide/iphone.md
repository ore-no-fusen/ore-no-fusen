# iPhone連携

[English](/en/user-guide/iphone)

PCの付箋をiPhoneへ送り、外出先でも確認できます。iPhoneで書いたメモ、画像、動画をPCの付箋として送ることもできます。

## 仕組み

| 項目 | 内容 |
|---|---|
| 中継 | ユーザー自身のGoogle Drive |
| iPhone受信 | PCから送った付箋をiPhone版に保存し、通知から開く |
| PC受信 | 自動で新規付箋として開く |
| iPhoneから送った画像・動画 | PC側へ保存後、中継データは削除 |

::: tip
開発者のサーバーに付箋本文を保存する方式ではありません。
:::

## 初回セットアップ

1. PC側の設定で **iPhone連携** を開き、**iPhone送信を有効にする** をONにして、PCをGoogle Driveへ接続します。
2. 表示されたQRコードをiPhoneで読み取り、Safariで開いて「ホーム画面に追加」します。
3. iPhone版を開き、PCと同じGoogleアカウントで接続します。
4. iPhone版で **通知を許可する** を押し、通知を許可します。
5. PC側に **準備完了** と表示されることを確認します。

## PCからiPhoneへ送る

1. PCで送りたい付箋の編集を終え、保存しておきます。
2. 付箋を右クリックし、**📱 iPhoneに表示** を選びます。
3. **iPhoneに送りました** と表示されたことを確認します。
4. iPhoneに届いた通知をタップし、送った付箋を開きます。

未設定の場合は、送信の代わりに設定画面の **iPhone連携** が開きます。上の初回セットアップを終えてから、もう一度 **iPhoneに表示** を選んでください。

## iPhoneからPCへ送る

1. iPhone側ページを開く
2. 本文を書く
3. 必要なら画像・動画を添付
4. **PCに送る** を押す

## 表示言語を変える

初期表示は日本語です。一覧画面右上の **🌐 EN** を押すと英語へ切り替わります。英語表示中は **🌐 日本** を押すと日本語へ戻ります。

選んだ言語はそのiPhone内に保存され、次回起動後も維持されます。PC版の言語設定とは連動しません。

届かない時: [困ったときに](/user-guide/troubleshooting)
