# 応援する・サポート

## サポート

問題や機能リクエストはアプリ内の「ご意見・ご要望」または「開発者とのやりとり」から送れます。

- [問い合わせ方法](/contact)

## 応援する・限定解除版

ore-no-fusen は無料で使えます。応援したい方には、限定解除版の購入と奉納帳への名前掲載という応援の形を用意しています。

### 限定解除版を購入する

公式サイトの [「ご購入について」ページ](https://ore-no-fusen.vercel.app/about-donation) から購入できます。現時点で解除される内容は **奉納帳への名前掲載** です。掲載は任意で、表示名が空欄の場合は掲載されません。

### 奉納帳を見る

応援してくれた方の名前は、[奉納帳ページ](https://ore-no-fusen.vercel.app/endroll) でお祭りの提灯のように流れていきます。新着の方の名前が前を流れたら、ぜひ拍手を送ってください。
