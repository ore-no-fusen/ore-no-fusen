## 最大の学び：媒体ごとに「入口」が違う

同じ素材を全媒体にメールしても効かない。媒体ごとに正しいドアがある。

```
窓の杜    → タレコミ投稿フォーム（ソフト紹介が本業）★効いた
Vector    → 作者登録＋ソフト登録（審査ゆるい・ほぼ載る）★完了
GIGAZINE  → 編集部メールでなく「ネタ投稿フォーム」＋ニュース性・画
ITmedia   → 自薦でなく PR TIMES 等プレスリリース経由
Product H → 出すだけでなく継続。点→線にする発信が要る
```
