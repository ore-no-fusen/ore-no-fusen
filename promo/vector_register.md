## 手順（画面でなぞるだけ）

### STEP 1. 作者パスワードを発行する
1. ここを開く → https://vecauthor.vector.co.jp/libauthor/author/new_password.php
2. **作者番号 `PA063685`** と **メール `huchiki8@gmail.com`** を入力
3. 折り返しメールでパスワードが届く
   - ※発行直後はエラーが出ることがある。出たら時間をおいて再試行（Vector公式の注意）

### STEP 2. 作者ページにログイン
1. ここを開く → https://vecauthor.vector.co.jp/libauthor/
2. 作者番号＋パスワードでログイン
3. 「ソフトの新規登録」を選ぶ

### STEP 3. 公開ファイルを用意する
- アップロードするのは **配布用ファイル1個**。下のどちらかでよい:
  - インストーラ（`.msi` / `.exe`）
  - もしくは zip
- いまの最新インストーラ（公式サイトからDLできるもの）をそのまま使えばよい
- 置き場所: 公式サイト https://ore-no-fusen.vercel.app/ からDLした本体

### STEP 4. フォームに下の「貼り付けテキスト」を入れる
各項目を、次セクションのテキストをコピペして埋める。

### STEP 5. スクリーンショットを添付
- 既存の宣伝素材が使える: `promo/promo.html` や `promo/frames-debug/` のキャプチャ
- 「Ctrl+Nで一瞬で開く」「Markdownで書ける」「iPhoneに飛ぶ」あたりが伝わる画を1〜3枚

### STEP 6. 申請 → Vector審査 → 掲載
- 審査はゆるい。フリーソフトなので基本通る。数日〜で掲載。

## 貼り付けテキスト（フォーム用）

> ⚠️ Vectorの制約に合わせてある:
> - **ソフトウェア名**＝半角英数・ハイフン・アンダースコア・ピリオドのみ（全角/空白/括弧NG）
> - **1行見出し**＝50バイトまで
> - **内容説明**＝2000バイトまで・連続改行禁止・HTML可

### ソフトウェア名（半角のみ）
```
ore-no-fusen
```
※日本語名「俺の付箋」は名前欄に使えない（全角NG）。日本語名は1行見出し・内容説明の中で名乗る。

### 1行見出し（50バイト以内）
```
Ctrl+Nで一瞬。Markdown対応の爆速デスクトップ付箋
```

### 内容説明（2000バイト以内・連続改行なし）
```

・散らかった付箋をボタンひとつで自動整列

・無料で、自分のデータが自分の中だけで完結するツールがほしい人
公式サイト: https://ore-no-fusen.vercel.app/
取り扱い: フリーソフト（無料）
動作環境: Windows 10 / 11
作者連絡先: huchiki8@gmail.com
```
